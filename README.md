Project Overview

This project analyzes e-commerce sales data using an interactive Power BI dashboard.

Key Performance Indicators

- Total Sales Amount
- Total Quantity
- Total Profit
- Average Order Value (AOV)

Dashboard Visualizations

- Sales Amount by State
- Quantity by Product Category
- Monthly Profit Analysis
- Sales Amount by Customer
- Quantity by Payment Mode
- Profit by Sub-Category

Objective

To present sales performance in a clear visual format and help users explore trends across states, products, customers, months and payment methods.
